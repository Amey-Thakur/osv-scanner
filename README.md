# Explainer media

Three renderings of one story: the stack-overflow denial of service fixed in
[google/osv-scanner#3032](https://github.com/google/osv-scanner/pull/3032).

| File | Length | Use |
| :--- | :--- | :--- |
| `spdx-recursion-fix.mp4` | 26.6s | The full four-beat explainer, H.264, 1080x1080 |
| `spdx-recursion-fix.gif` | 26.6s | The same, as a looping GIF |
| `spdx-recursion-fix-loop.gif` | 6.5s | The crash and the fix only, trimmed to loop |
| `spdx-recursion-fix-card.png` | still | A single-frame summary card, 1200 x 1200 |
| `spdx-recursion-fix-poster.png` | still | The video poster frame, 1080 x 1080. Use as a custom thumbnail |
| `spdx-recursion-fix-social.png` | still | The repository social preview, 1280 x 640 |

This branch is deliberately an orphan. It shares no history with `main`, which
sits at the upstream merge commit, or with `fix/spdx-recursion-depth-limit`,
which is the branch that was reviewed and merged. Neither should carry media
that is not part of the change.

Marks are the official ones, used to denote what they name: the OSV-Scanner
wordmark from `docs/assets/logo.png` in this repository, and the GitHub
organisation avatars for `google` and `github`.
